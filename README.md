# linktree
página pessoal

# o que foi usado?
- HTML5 (estrutura)
- CSS3 (estilização)
- VScode (editor)

# o que possuí?
- logo
- foto de perfil
- links redirecionando para LinkedIn e GitHub
- links de contatos por E-mail e WhatsApp
- resposividade para mobile

# como executar
1- clone o repositório no seu editor de código

2- abra o "index.html"

3- se tiver a extensão LiveServer, no "index.html" aperte o atalho "ALT+L + ALT+O"
